# English with Vincent

Интерактивная тетрадь по английскому для детей 9–10 лет с проводником Винни — пуделем. Четыре урока: **Present Simple / Present Continuous**, **There is / There are**, артикли **a / an / the**, **was / were / could** (по учебнику Go Getter 2). Ученик вводит имя, а Винни зовёт его по имени.

В каждом уроке: объяснение правила по-русски, озвученные примеры, пять типов упражнений (выбор, ввод с клавиатуры с проверкой написания, сортировка, конструктор предложений, рассказ с пропусками), баллы, наклейки за этапы и медаль за урок. Прогресс сохраняется в браузере. Реплики Винни озвучены молодым британским голосом Archie из ElevenLabs Eleven v3.

Запустите любой локальный статический сервер из корня проекта, например `python3 -m http.server 4173`, и откройте http://localhost:4173 (ES-модули не работают с `file://`).

## Для агентов и разработчиков

Над проектом работают несколько ИИ-агентов (Claude Code — методика, тексты, движок, озвучка; ChatGPT — иллюстрации). Общий контекст, схема данных уроков и методические правила — в `AGENTS.md`, журнал передач — в `tasks/handoff.md`, ТЗ на картинки — `tasks/illustrations-spec.md`, все фразы озвучки — `tasks/audio-spec.md`. Проверка данных уроков: `node tools/check-lessons.mjs`.
