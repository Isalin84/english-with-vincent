# English with Vincent

Интерактивная игра для изучения английского языка. Первый урок помогает отличить **Present Simple** от **Present Continuous** с помощью Винни — пуделя-проводника.

Игра включает объяснение правил, озвученные примеры, упражнения, баллы, серии правильных ответов и финальную медаль. Реплики Винни озвучены молодым британским голосом Archie из ElevenLabs Eleven v3.

Откройте `index.html` или запустите любой локальный статический сервер из корня проекта.

## Для агентов и разработчиков

Над проектом работают несколько ИИ-агентов (Codex и Claude Code). Общий контекст, инвентарь аудио и методические правила — в `AGENTS.md`, журнал передач — в `tasks/handoff.md`.
