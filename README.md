# English with Vincent

Интерактивная игра для изучения английского языка. Первый урок помогает отличить **Present Simple** от **Present Continuous** с помощью Винни — пуделя-проводника.

Игра включает объяснение правил, озвученные примеры, упражнения, баллы, серии правильных ответов и финальную медаль.

Откройте `index.html` или запустите любой локальный статический сервер из корня проекта.
